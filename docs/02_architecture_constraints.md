# Restricciones de Arquitectura

## Decisiones tecnológicas

### Frontend

Se utilizará React para desarrollar la interfaz web del sistema ERP, permitiendo una interacción dinámica con los usuarios.

### Backend

Se utilizará Java con Spring Boot para implementar la lógica de negocio y los servicios del sistema.

### Base de datos

Se utilizará PostgreSQL para almacenar la información de productos, proveedores, órdenes de compra e inventario.

### Comunicación

La comunicación entre la aplicación web y el backend se realizará mediante una API REST utilizando HTTPS.

### Control de versiones

GitHub será utilizado para almacenar la documentación y gestionar las versiones del proyecto.
