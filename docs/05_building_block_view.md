# Vista de Bloques de Construcción

## Arquitectura del sistema

El sistema ERP está compuesto por tres contenedores principales:

### Aplicación Web

Desarrollada con React. Permite a los usuarios gestionar productos, proveedores y órdenes de compra.

### API ERP

Desarrollada con Java Spring Boot. Contiene la lógica del negocio y procesa las solicitudes del sistema.

### Base de Datos

Utiliza PostgreSQL para almacenar la información del sistema.
