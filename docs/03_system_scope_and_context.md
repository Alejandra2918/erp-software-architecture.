# Alcance y Contexto del Sistema

## Descripción

El sistema ERP permite gestionar los procesos principales de la empresa, especialmente el módulo de compras, donde se administran productos, proveedores y órdenes de compra.

El sistema interactúa con diferentes usuarios y sistemas externos para facilitar la gestión de información empresarial.

## Actores principales

- Administrador de Compras: registra productos, proveedores y gestiona compras.
- Gerente: consulta información y reportes.
- Sistema Contable Externo: recibe información financiera.
