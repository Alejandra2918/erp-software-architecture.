# Introducción y Objetivos

## Objetivo del sistema

El sistema ERP tiene como objetivo integrar los procesos administrativos de la empresa mediante una plataforma que permita gestionar compras, inventario, proveedores y reportes.

## Requisitos del módulo de compras

- Registrar productos.
- Registrar proveedores.
- Crear órdenes de compra.
- Consultar historial de compras.
- Generar reportes de compras.
